## Отличия от расширенного промпта

Основной кейс R1–R6 реализован. Следующие расширения не заявляются готовыми:

- Настоящие OpenAI-эмбеддинги не сгенерированы без ключа: кэш содержит TF-IDF, скрипт генерации OpenAI-векторов реализован.
- LLM не извлекает факты и не пишет свободную прозу: факты извлекаются правилами, модель выбирает порядок проверенных предложений. Это осознанное ограничение для строгого grounding.
- Нет универсального семантического проверяющего произвольных утверждений и нормализатора свободных дат вроде «14 ноября». Текущий critic принимает только проверяемую грамматику; числовые формы «70 тыс.» отдельно нормализуются.
- Живые вызовы API и независимая оценка LLM-судьёй не выполнены. EVAL — офлайн.
- Непоказанные кандидаты в trace обозначены id; подсказки не называют имён.
- Нет parse-query, NVIDIA, deployed URL, векторной БД, обучения весов и реальных календарей.
