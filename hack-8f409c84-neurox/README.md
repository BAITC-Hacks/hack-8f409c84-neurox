# Умный подбор подрядчиков

Проект команды для **HackAlem AI 2026**
Кейс **#79-lite — Умный подбор подрядчиков**

## О проекте

Мы разрабатываем сайт, который помогает подобрать подрядчика для мероприятия.

Пользователь указывает основные параметры своего мероприятия, после чего система анализирует доступных подрядчиков и предлагает до трёх подходящих вариантов.

Главная задача проекта — не просто показать список подрядчиков, а объяснить, почему были предложены именно эти варианты.

## Что учитывается при подборе

При поиске учитываются параметры заказа:

* город;
* дата мероприятия;
* тип мероприятия;
* категория подрядчика;
* бюджет;
* длительность мероприятия;
* язык.

Система также учитывает информацию о самом подрядчике, включая его специализацию, стоимость, доступность на выбранную дату и описание.

Если подрядчик занят в указанную дату, он не должен попадать в результаты.

## Как будет работать сайт

Работа сайта строится по простой схеме:

```text
Пользователь
     ↓
Заполняет параметры мероприятия
     ↓
Система получает запрос
     ↓
Проверяет доступных подрядчиков
     ↓
Отбирает подходящих кандидатов
     ↓
Сравнивает их с условиями пользователя
     ↓
Формирует рекомендации
     ↓
Показывает до 3 подрядчиков
     ↓
Объясняет причину каждой рекомендации
```

## Основная идея

Мы хотим сделать подбор понятным для пользователя.

Вместо большого списка подрядчиков пользователь получает небольшое количество вариантов, которые подходят под его запрос.

Для каждой рекомендации сайт должен показывать конкретную причину выбора: соответствие бюджету, формату мероприятия, языку, длительности или другим параметрам.

## Результаты поиска

Сайт должен корректно обрабатывать разные ситуации.

**Подрядчики найдены**
Пользователь получает до трёх подходящих вариантов.

**Подходящих подрядчиков меньше трёх**
Сайт показывает доступное количество и объясняет, почему вариантов мало.

**В городе нет нужной категории**
Пользователь получает понятное сообщение об этом.

**Подрядчики есть, но никто не подходит**
Система сообщает причину: например, ограничения по бюджету, формату или доступности на выбранную дату.

## Данные

В проекте используется датасет, предоставленный организаторами HackAlem AI.

Он содержит **66 анонимизированных профилей event-подрядчиков**.

В данных содержится информация о категориях подрядчиков, городе, стоимости, форматах мероприятий, языках работы, длительности, занятых датах и описании.

## Что важно в нашем решении

Основной упор проекта делается на:

* понятный процесс подбора;
* конкретные причины рекомендаций;
* учёт занятости подрядчиков;
* работу с бюджетом и параметрами мероприятия;
* корректную обработку ситуации, когда вариантов мало или их нет;
* одинаковый результат при повторении одинакового запроса.

## Формат проекта
