# EventMatch

Проект для кейса HackAlem AI #79-lite — подбор подрядчиков для мероприятий.

## О проекте

Идея проекта — упростить выбор подрядчика из уже существующего каталога.

Пользователь указывает параметры своего мероприятия: город, дату, тип мероприятия, нужную категорию подрядчика и бюджет. При необходимости также можно указать язык и длительность мероприятия.

После этого программа проверяет подходящих подрядчиков и выводит до 3 вариантов. Вместе с каждым вариантом показывается причина, почему он попал в рекомендации.

Например, система может указать, что фотограф свободен в выбранную дату, работает в нужном городе, снимает свадьбы, подходит по бюджету и работает на казахском языке.

## Что учитывается при подборе

При поиске подрядчиков учитываются:

* город;
* категория;
* дата и занятость подрядчика;
* формат мероприятия;
* бюджет;
* язык;
* максимальная длительность работы;
* информация из описания подрядчика.

Подрядчики, которые заняты в выбранную дату, не показываются.

Если подходящих вариантов меньше трёх, программа выводит столько, сколько удалось найти. Если вариантов вообще нет, пользователь получает объяснение причины.

## Данные

Используется датасет, предоставленный организаторами HackAlem AI.

В нём находится 66 профилей подрядчиков. Для каждого профиля доступны категория, город, стоимость, поддерживаемые форматы мероприятий, языки, занятые даты, максимальная длительность работы и описание.

## Логика работы

Примерный процесс выглядит так:

```text
Запрос пользователя
        |
        v
Поиск подрядчиков нужной категории и города
        |
        v
Проверка занятости на выбранную дату
        |
        v
Проверка формата мероприятия и бюджета
        |
        v
Проверка языка и длительности
        |
        v
Оценка оставшихся кандидатов
        |
        v
До 3 подходящих подрядчиков
        |
        v
Объяснение результата
```

Мы стараемся не использовать общие объяснения вроде «этот подрядчик отлично вам подходит».

Причина рекомендации строится на конкретных данных профиля.

Например:

```text
Тэммари Собаку
Фотограф, Астана
Цена: от 250 000 ₸

Подходит под бюджет 300 000 ₸ и работает со свадьбами.
Доступны русский и казахский языки, максимальная длительность работы — 12 часов.
```

## Возможные результаты

Программа различает три основных случая:

1. Найдены подходящие подрядчики.
2. В выбранном городе нет подрядчиков такой категории.
3. Подрядчики есть, но никто не прошёл условия запроса.

В третьем случае программа также показывает причину. Например, все кандидаты могут быть заняты на выбранную дату или не подходить по бюджету.

На данный момент планируем использовать:

* Python
* Pandas
* Streamlit
* JSON/JSONL

При необходимости для анализа описаний подрядчиков может использоваться семантическое сравнение текста.

## Что хотим показать на демо

Для проверки проекта планируем использовать несколько разных запросов:

* популярная категория, где есть много кандидатов;
* редкая категория, где вариантов мало;
* запрос, для которого подходящих подрядчиков нет;
* одинаковый запрос с разными датами, чтобы показать влияние занятости.

При одинаковых входных параметрах порядок рекомендаций должен оставаться одинаковым.

## Ограничения

Проект занимается только подбором подрядчиков. Бронирование, отправка заявок и связь с подрядчиком не реализуются.

Также проект работает с небольшим датасетом, поэтому задача заключается не в поиске подрядчиков по всему Казахстану, а в выборе наиболее подходящих вариантов среди предоставленных данных.
